# Authored development fixtures

These four finite graphs were constructed to test semantic handling. They are **not** held-out application tasks, natural bridge defects, measured LLM behavior or a research result. The namespace mismatch and unsafe intermediate state are deliberate controlled development inputs.

The evidence interval is an explicit **simulation assumption**, not a claim that a bridge was observed in 1970 or certified until 2100. Actual wire-derived manifests require separately recorded observation times, pinned source/profile provenance and validated projection logic.

`scripts/create_development_fixtures.py` constructs these inputs. The independent oracle and certificate checker evaluate the supplied runtime contract only. No private gold is made available to an admission arm.
